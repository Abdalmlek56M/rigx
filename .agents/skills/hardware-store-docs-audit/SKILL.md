# تدقيق وثائق HARDWARE STORE

## الإجراء

1. اقرأ `AGENTS.md` كاملًا أولًا، وحدد نطاق المهمة والنسخة/الحزمة المقصودة.
2. ابدأ من الوثيقة المالكة للمعلومة: `ROADMAP.md` لترتيب المراحل، `OPEN_QUESTIONS.md` للقرارات المعلقة، `BUSINESS_RULES.md` لسياسة العمل، وERD للعلاقات والقيود. استخدم `REQUIREMENTS_TRACEABILITY.md` لربط المتطلب بمصدره ولا تجعله بديلًا للمصدر الأصلي.
3. افحص الملفات المرتبطة بالمهمة فقط، وسجّل لكل معلومة: الحالة (معتمدة/مقترحة/معلقة)، مصدر الحقيقة، والمراجع التي تكررها.
4. قارن التعريفات ذات الصلة بين الوثائق، وميّز التعارض الحقيقي من اختلاف الصياغة أو مستوى التفصيل. لا تستنتج موافقة المالك من علامة إنجاز أو مثال.
5. استشهد بمسار الملف ورقم السطر لكل نتيجة، وصنّف شدتها واربطها بأثرها العملي. اذكر ما تعذر إثباته.
6. اقترح أقل تصحيح متماسك وحدد الوثائق التابعة التي تحتاج مزامنة؛ لا تغيّر سياسة عمل أو قرارًا معلقًا.

## شكل التسليم

اعرض النتائج أولًا حسب الشدة، ثم الحقائق المؤكدة، والتوصيات الفنية، والافتراضات/القرارات المطلوبة. لا تصف تدقيقًا آليًا أو مقارنة نسخة/أرشيف بأنها تمت إلا إذا شغّلتها وسجلت نتيجتها.
