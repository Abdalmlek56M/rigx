# @rigx/api-client

Typed client for the RIGX API. The types are generated from `openapi.v1.json`, the API contract produced by the backend.

- `openapi.v1.json` is the contract. `ApiContractTests` fails when the backend changes and this file is stale. To update it, run `UPDATE_API_CONTRACT=1 dotnet test tests/HardwareStore.Api.Tests --filter ApiContractTests`.
- `src/generated/schema.d.ts` is generated by `npm run generate` (it also runs on `npm install`) and is never committed.
- `npm run typecheck` checks the package (strict), and `npm test` runs the wrapper tests.

```ts
import { createRigxClient, unwrap, ApiError, STEP_UP_HEADER } from "@rigx/api-client";

const api = createRigxClient({ baseUrl: process.env.NEXT_PUBLIC_API_URL });
const page = await unwrap(api.GET("/api/v1/store/items", { params: { query: { page: 1 } } }));

try {
  await unwrap(api.POST("/api/v1/identity/email-code/verify", { body: { email, code, rememberDevice: true } }));
} catch (error) {
  if (error instanceof ApiError) show(error.message, error.fieldErrors, error.problem.attemptsLeft);
}

await unwrap(api.DELETE("/api/v1/admin/system/trash/{kind}/{id}", {
  params: { path: { kind, id } },
  headers: { [STEP_UP_HEADER]: code }
}));
```

Conventions (also in the document's description):
- Errors are ProblemDetails: `title`, `status`, field `errors`, plus extensions such as `attemptsLeft`.
- Lists are `{ items, page, pageSize, total }`. `page` starts at 1 and `pageSize` is at most 100.
- Session = HttpOnly cookie (`credentials: "include"`). Unsafe methods send `X-CSRF-TOKEN`; the client fetches and refreshes it.
- Each operation's description lists the permission it needs and whether it needs a step-up code.
