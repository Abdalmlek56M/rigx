# مذكرة تسليم مراجعة RBAC

> **وثيقة تاريخية:** تسجل تسليم نواة RBAC المبكرة فقط. حالة M3 الحالية ومرجع الاستلام المعتمد موجودان في [MODEL_HANDOFF.md](../MODEL_HANDOFF.md) و[PROGRESS.md](../PROGRESS.md). لا تستخدم عبارة «غير منفذ» أدناه لوصف حالة المشروع الحالية؛ كانت صحيحة وقت إعداد هذه المذكرة.

## المنفذ
- كتالوج مركزي للصلاحيات الـ32 الموثقة في USERS_ROLES_PERMISSIONS.md، بمعرفات ثابتة.
- PermissionRequirement وPermissionAuthorizationHandler؛ التحقق قائم على Permission claim مطابق ومعروف، مع اشتراط هوية مصادق عليها وعدم وجود تجاوز للدور.
- تسجيل DI داخل Identity، وربط التسجيل في API Host، وامتداد RequirePermission لـMinimal API.
- اختبارات مركزة للمنح والرفض والمجهول والصلاحية غير المعروفة وتعدد الصلاحيات. سجل التنفيذ يوثق نجاح 7/7.

## غير المنفذ
- تسجيل الدخول، إنشاء الحسابات، JWT وRefresh Tokens.
- تخزين دائم للأدوار/الصلاحيات وإصدار Permission Claims من مصدر موثوق.
- لم تكتمل M3؛ المطلوب التالي مراجعة معمارية وأمنية مستقلة لكود RBAC.

هذه الحزمة للمراجعة فقط، ولا تمثل اعتمادًا أمنيًا أو إغلاقًا لـM3.
