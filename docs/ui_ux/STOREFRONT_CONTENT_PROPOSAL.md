# Storefront Content Capability Proposal

**الحالة:** مقترح مستقبلي غير منفذ. لا يضيف Migration أو Endpoint في الجولة الحالية.

## السلوك الحالي

- الصفحة الرئيسية تجلب أحدث المنتجات المنشورة من Catalog API.
- أول 4 منتجات تظهر كـFeatured، والمنتجات التالية تظهر كـLatest.
- التصنيفات الظاهرة هي التصنيفات الفعالة مرتبة حسب `SortOrder` ثم الاسم.
- الماركات الظاهرة هي الماركات النشطة مرتبة بالاسم.
- لا توجد عروض أو خصومات أو بيانات ثقة مزعومة.

هذا السلوك ظاهر للمشرف داخل لوحة التحكم، وليس وعدًا بقدرة CMS موجودة.

## القدرة المقترحة

إضافة `Storefront Content` في مرحلة معتمدة لاحقًا، وتشمل:

- Hero title وsubtitle وCTA label/link.
- Featured products/categories مختارة يدويًا مع fallback آلي.
- ترتيب الأقسام وإظهارها/إخفاءها.
- Brand strip المختارة.
- Content slots للثقة والشحن والضمان، مع بيانات يوفرها المالك فقط.

## حدود التصميم المقترحة

- جدول إعدادات Singleton للمحتوى البسيط.
- جداول ربط للعناصر المختارة إن احتاج الاختيار اليدوي.
- Public read API وAdmin update API.
- Permission مستقلة إن لم تكف صلاحيات Catalog الحالية.
- Cache invalidation عند تعديل الإعدادات أو نشر عنصر مرتبط.

## بيانات يحتاجها المالك

- نصوص Hero وCTA المعتمدة.
- الشعارات والصور المرخصة.
- المنتجات والتصنيفات التي يجب تثبيتها.
- سياسات الشحن والضمان والدفع التي يمكن عرضها.
- ترتيب الأقسام المطلوب.

لا تبدأ Migration أو تنفيذ هذه القدرة قبل اعتماد النطاق والصلاحية وسياسة المحتوى.
