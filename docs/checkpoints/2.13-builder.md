# Checkpoint: 2.13 Builder v2

Date: 13 Nov 2026

## Done
- Free builder over published stock items (`BuilderItemService` in Retail, `Host/HardwareStore.Api/Builder/` for orchestration, rules in PcBuilder `Domain/BuilderRules.cs`).
- Slots CPU, BOARD, RAM, GPU, SSD, PSU, CASE, COOL come from categories with "show in builder" + code = slot (sub-categories included). A part's slot is its item's category; one part per slot, quantity 1–4, max 8 parts.
- Compatibility from category specs flagged compatibility: a shared key must share a value (lists split by `,` `/` `|`); `max_x` on one part limits `x` on others (OverLimit); missing values never conflict.
- Power: estimate = sum of `power_w` × quantity of all parts except PSU; PSU `power_w` = output. Over 100% = conflict, over 80% = warning (owner decision 13 Nov 2026).
- Price (owner decision 13 Nov 2026): every part at its in-build price when the build has a processor and a motherboard, else the alone price. New order price option `InBuild` (`OrderPriceOption` Alone/WithBoard/InBuild). Online it needs a CPU and a BOARD among the InBuild lines (`OrderRules.EnsureBuildPrice`, `BuildPriceRule` passed by Host in `CheckoutPolicy` and to the quote); store and POS are free.
- Options list keeps sold-out items (IsAvailable=false, shown struck and locked) and marks incompatible ones with their issues.
- Check result: unit/line price and availability per part, missing codes (never throws, so saved links keep working), issues, power estimate, PSU capacity, total, CanOrder, CartLines (checkout lines for "add all to cart").
- "عدّل فيها" (owner decision 13 Nov 2026): from a published BLD, the same models from FREE stock (same condition preferred, then cheapest); the build itself is untouched; unmatched parts listed.
- Quote: `POST /api/v1/builder/quote` returns the existing QuoteDocument (name, usage, parts, total, no invoice number); 409 if the build cannot be ordered.
- Saved builds (migration M32, PcBuilder table `saved_builds`): token 16 random bytes base64url, optional owner, name ≤100, usage, parts jsonb, row version. Anyone can save (link = key; rate limit `builder-save` 20 / 10 min per IP); a signed-in saver owns it and is the only one who can update (row version, 409) or delete; signed-out saves can never change; max 50 per account. Save refuses unpublished parts but allows conflicts. Reading by token re-checks live prices.
- PC-builder templates removed (D7): endpoints `/api/v1/pc-builder/*` and `/api/v1/admin/pc-builder/*`, tables `pc_build_templates`, `pc_build_slots`, `pc_build_slot_options` dropped by M32 (`M32_SavedBuilds`).
- Tests: unit `BuilderRulesTests`; integration `BuilderTests` (slots, options, check, checkout with InBuild cart lines, quote, saved builds owner/anonymous, from-build, old routes gone); `BuilderMigrationTests` (M32). Full suite 656/656.
