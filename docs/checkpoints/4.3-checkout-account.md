## Decisions — delegated to Claude, defaults chosen
- Order lines by public code instead of exposing item ids publicly.
- Code sign-in = one 6-digit input (`one-time-code`), "remember me" on by default; Google sign-in always remembers the device.
- Build cart line with quantity N → N order lines (the API sells one build per line).
- Placed order is passed to `/checkout/success` through `sessionStorage` (`rigx.lastOrder`); without it the page links to tracking help.
- Pickup label uses the settings pickup address; checkout upfront note is built from settings (no fixed numbers); InstaPay/wallet numbers are not shown before confirmation.
- Email change and linking Google ask for the emailed step-up code (backend rule).
- Address governorate saved as the governorate name (backend field is free text), picked from the shipping-rates list.
- Invoice: watermark = store name in CSS (no logo field in the invoice branding), QR only when `showWarrantyQr`; place line from settings pickup address.
- FAQ page shows General-scope questions grouped by topic; YouTube embeds only via `youtube-nocookie`.
- Policies render as plain text (paragraphs, `#` headings, `-` lists); no HTML.
