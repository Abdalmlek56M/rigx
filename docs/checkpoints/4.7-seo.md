## Decisions (delegated)
- The slug lives on the stock item (what the store sells and what the product page shows), not on the catalog product.
- A name with no Latin letters or digits gets `item` (then `item-2`…).
- A rename only changes the slug when the base changes. Follow-up (owner request 19 Nov 2026, a published link must work forever): the old slug is kept in `stock_item_old_slugs` (`StockItemOldSlug`, migration M50 Retail, slug primary key, cascade with the item). `GET /api/v1/store/items/{key}` finds an item by an old slug too and returns the current slug, so `/p/<old-slug>` answers 308 to the new one. Old slugs stay reserved (`StockItemSlug.Choose`): a new item with the old name gets `-2`; only the same item may take its own old slug back. Sold-out items keep their page and sitemap entry (unchanged since 4.6).
- English pages are `noindex` while English is switched off in settings.
- Builds keep `/builds/BLD-01` (the owner decision covered products only).
- No Article markup: there is no public article page yet.
