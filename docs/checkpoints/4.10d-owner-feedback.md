## R4-B — Stock intake and builds (biggest slice)
1. **Intake type at the start:** "قطعة منفردة" or "تجميعة". A build intake lists its parts inside it. On receiving, each part becomes its own stock unit (RX code, serial, specs) **inside a new draft build**, so each part can be swapped or sold alone later. Adding parts from stock is still possible. This replaces the current two-step flow (add parts one by one, then attach them).
2. **Collapsible part cards:** each part card collapses with an arrow. The title becomes the model name ("i5 12400F") instead of "القطعة 1".
3. **Missing required fields:** the save button stays enabled. Pressing it scrolls to the first missing field, marks it red, and opens a summary alert ("ناقص: السعر في كارت الشاشة").
4. **Draft autosave:** purchase, stock item and build forms keep the unsaved draft locally (per user, per form) and restore it after a refresh or crash, with "استرجاع المسودة / تجاهل".
5. **Category, then subcategory:** after picking a category, a second picker shows its subcategories if there are any.
6. **Searchable pickers** (brand, category, model): type to filter, or open the list. Brand adds a new one inline.
7. **Repeat line** ("كرر السطر") for identical pieces.
8. **Custom spec fields per category** (e.g. RAM → CL): the owner adds and removes fields from the category page. Keep it to name, type (number, text, choice) and unit.
9. **Sale-price options per category** (bundle rules): per category the owner turns each price on or off: "لوحدها", "مع بوردة / باندل", "جوه تجميعة". Example: GPU = alone + inside a build only. The storefront and POS hide a price that is turned off and never break when one is missing. The current names ("زيادة مع بوردة", "زيادة لوحدها") are reworded so they are clear.
10. **Inventory item page:** a clear "عرض / تحكم" action on every row, opening a page with the photo gallery (reorder, delete, set main, duplicate), details, history, and actions (edit, repeat, hide, sell).
