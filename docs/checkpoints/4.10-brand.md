# Checkpoint: Phase 4.10 Brand — part a (storefront redesign)

Date: 19 Nov 2026

## Done (owner feedback 19 Nov 2026, all 13 points)
- **Direction "Workshop white"**: light is the default (a saved choice still wins; the OS setting no longer picks dark). Near-white page `#f5f5f2`, white surfaces, graphite ink, the RIGX orange `#ff6a2b` kept as the only accent. Dark mode kept (`[data-theme="dark"]`); its `--carbon` is a lifted graphite `#2c3037` so selected chips and dark cards stay visible on the dark page. New token `--chrome` (graphite in both themes) for the top strip, footer and admin sidebar. Also `--orange-soft`, `--whatsapp`, `--shadow-soft`, `--shadow-lift`; radii 10 / 14 / 20 px.
- **Type**: headings (h1/h2) in Alexandria 600/700 (Arabic + Latin, geometric, matches the wordmark); body stays IBM Plex Sans Arabic. Orange text selection, orange caret.
- **Layout**: one `shell` container (`globals.css` `@utility shell`): 1440 px wide with a fluid 16–48 px gutter, used by every storefront section, header and footer (was 1240 px).
- **Header**: light and sticky, gains a soft shadow on scroll (CSS scroll-driven). Nav pills from `lg`; the menu sheet below `lg`. Search is a rounded field with a visible search icon and the placeholder "دوّر على قطعة أو تجميعة" (no codes). Account / theme / EN / cart are round icon buttons; the cart is icon-only with an orange count badge that pops on change. Logo is drawn in `currentColor`.
- **Login**: card with the Google button as Google's own full-width pill (`shape: "pill"`, black in dark mode; the host is `color-scheme: light`, which removes the white box), divider only when Google is configured, pill submit buttons; a graphite side panel on `lg` lists what the account holds (orders, warranty, invoices). The mono "NEW · USED · BUILDS" kicker is gone.
- **Motion** (all off under `prefers-reduced-motion`): page sections rise in one after another, header shadow on scroll, badge pop, icon swap on the WhatsApp button, back-to-top pop-in, tile arrows slide on hover, chip press, soft focus rings on every field.
- **Recommender chips**: usage chips have icons (gamepad, film, book, broadcast), clear hover / selected (graphite fill + check on the budget) / press states, focus ring; WhatsApp-green send button. The "مش عارف تختار؟" kicker now sits under the title.
- **Footer**: "تواصل معنا"; contact rows with round icons, aligned; 2 columns on phones; "إزاي بنشتغل", "المقالات" and the dead "/support" button removed. Help lists only **published** policies (`features/policies/published-policies.ts`, also used by the sitemap) plus warranty lookup and FAQ, so no policy link can 404.
- **WhatsApp**: every customer-facing WhatsApp link opens in the same tab (social links still open a new tab). Floating button is WhatsApp green with a soft breathing ring; its menu's "/support" item became warranty lookup.
- **Back to top**: round arrow, bottom-start (bottom-right in Arabic), after 480 px of scroll.
- **Account**: "unlink Google", "delete" and "sign out" are outlined icon buttons (unlink / trash / log-out icons) with an in-place red confirm; login-method rows show the email and Google marks.
- **Governorate**: the address form always uses the list of the 27 governorates (from the shipping rates, which come from `EgyptGovernorates`). API: `CustomerAddressService` rejects any Egyptian address whose governorate is not one of the 27 (400 "Unknown governorate."), accepts a code (`ALX`) and stores the Arabic name (`EgyptGovernorates.NameOf`). Tests in `CustomerAddressTests`.
- **Polish pass**: home hero rebuilt (big display headline, four start tiles with icons, warm orange glow), category tiles with icon circles, service cards with icons, builder promo slots with drawn icons (no ✓ glyphs); RX/BLD codes no longer shown on item cards, build cards, product or build pages (still in links to the builder, WhatsApp messages, admin, invoices); catalog grid wider with a sticky filter panel; pill condition badges; cart toast moved under the header near the cart; checkout sign-in prompt is a button; every unicode ✓ ✕ › glyph in the storefront replaced by drawn icons.

## Decisions (delegated)
- Light default ignores the OS dark setting (owner asked for white as the primary look); the toggle stays.
- Orange kept: it is the brand X and reads well on white; WhatsApp green only on WhatsApp actions.
- Hiding product codes from customers (08-brand-direction §2) done for cards and pages; WhatsApp message templates keep the code because staff close orders on WhatsApp.
- Admin WhatsApp links keep opening a new tab (staff keep their place); the same-tab rule is for customers.
- Existing addresses with a free-text governorate still show it in the form; saving requires picking one of the 27.
