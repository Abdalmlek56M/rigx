# 4.12: owner visual round (25 Nov 2026)

The owner reviewed the live site with screenshots and asked for a "wow" level of finish. This file is the work list; each batch runs in its own session. **Wording bar:** every text (storefront, admin, emails, invoice) must read like an experienced, trusted Egyptian store wrote it: plain, specific, calm, never AI-sounding or showy.

## Facts checked in the code (25 Nov 2026)
- Product description: the backend has `ShortDescription` / `Description`, but the admin stock form does not expose them and the product page does not show them.
- Partner picker (`PartnerFields`) exists in purchases, build parts and the unit partner dialog, not in the quick add-item form. It is also hidden silently when the partner list fails to load (`fetchPartners().catch(() => [])`).
- Admin order tabs show the **current** status only: a completed order is under "Completed", not "Confirmed". This is by design.

## Batch 1: storefront look (cards, photos, product page)
1. Photos: cards fill the square frame (`object-cover`, no grey blurred edges); the product gallery frame follows the photo's own ratio so the whole photo shows with no edges. Replace `PhotoBackdrop` where it shows grey.
2. Item cards look empty: add 2 to 3 key specs, warranty and condition in a tidy row; same in the list view.
3. "ما القطعة التي تبحث عنها؟" category cards: bigger, better spacing, photo or strong icon.
4. "All categories" mega menu: spacing and the recent-item tile.
5. Product page: specs grid with an icon per spec and stronger values (translate `yes`/`no`); purchase info without payment methods, tidy, and remove the repeated "الشحن" under "الاستلام والشحن".
6. Cart line layout (name, condition, warranty, price, delete).
7. Quick look: scrolling at the end of the window must not scroll the page behind (`overscroll-behavior: contain`).
8. Maintenance card: hot look by default (red/orange glow, high temperature), cools down on hover (blue, the temperature counts down).
9. Filters: category, brand and the other groups collapse/expand; an icon beside each category, picked by the owner in the admin from a ready icon set.
10. Buy-button hover: new colour (not grey), two diagonal fills from bottom-right and top-left meeting in the middle.
11. Sign-in page: the animated background covers the whole page; form card stays readable; off for reduced motion.
12. Toasts: clear, top of the screen, calm style, everywhere.
13. Live search everywhere (storefront header, builder part search, admin lists) with a debounce; the builder search gets a search icon.
14. Icons across the site in the site's colours (not dull grey).
