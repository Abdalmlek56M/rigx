# Checkpoint: 2.8 Notify-me

Date: 14 Nov 2026

## Done
- Public `POST /api/v1/requests` type NotifyMe: RX code → its model name, key and category; typed model → key. Unknown code 404; model available now 409; same phone + open request for the model → same code returned (replaces the 10-min duplicate guard for this type).
- Job every 10 min (`BackInStockJob`): open (New/Following) unmatched requests whose model has an available published item get `available_item_code` / `available_at_utc` (cheapest by price, then code). Email queued if an email was given (subject "القطعة اللي طلبتها اتوفرت", link `Sales:ItemBaseUrl` + code). The request stays open.
- Admin:
  - `GET /api/v1/admin/requests/back-in-stock` (Requests.View): wa.me link + text from the WhatsApp template `BackInStock`, placeholders {الاسم} {القطعة} {اللينك}.
  - `POST /api/v1/admin/requests/{id}/back-in-stock/sent` (Requests.Manage): closes the request.
  - `GET /api/v1/admin/requests/demand?from&to` (default last 30 Cairo days): model, category, total, open, notified, last requested, available now.
- Dashboard `notifyMeDemand`: top 5.
- Migration M39 (Storefront): `model_key`, `category_id`, `available_item_code`, `available_at_utc`, `notified_at_utc` + partial index.
