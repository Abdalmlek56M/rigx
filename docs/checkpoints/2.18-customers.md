# Checkpoint: 2.18 Customers admin

Date: 14 Nov 2026

## Done
- Permissions `Customers.View`, `Customers.Manage` (M37 grants them to roles holding `System.ManageUsers`).
- Endpoints:
  - `GET /api/v1/admin/customers?search=&page=` (25 per page, order count, total spent, last order).
  - `GET /api/v1/admin/customers/{id}` (360: profile, login methods, restrictions, active sessions, note, governorate, stats, lead source, usage, orders incl. guest/POS by phone flagged `linkedToAccount`, warranties, requests, blacklisted flag).
  - `GET /api/v1/admin/customers/{id}/view-as` (read-only, audited `Customer.ViewedAs`).
  - `PUT /api/v1/admin/customers/{id}/note`, `POST /{id}/login-code` (202), `POST /{id}/google/unlink`, `POST /{id}/sign-out-all`.
  - `POST /api/v1/admin/customers/{id}/merge` `{sourceAccountId}` (step-up).
  - `POST /api/v1/admin/retail/warranties/{id}/extend` `{months, reason}` (`Sales.ProcessReturn`).
  - Customer `GET /api/v1/account/requests` (no internal note, no expected resale).
  - Suspend and blacklist reuse the existing restriction and blacklist endpoints.
- Stats: order count and last order ignore cancelled; total spent = delivered + completed totals minus refunds; lead source and usage from the earliest order that has them; governorate from the default address, else the latest order.
- Ownership: one rule (`Retail/Domain/CustomerRules.CustomerOwnership`) for list, 360 and warranties.
- Merge: orders, warranties, requests and saved builds move first; then Identity moves addresses and the Google link (only if the target has none), fills an empty phone, appends the note, and closes the source (`merged_into_account_id`, inactive, sessions revoked). Every step is idempotent, so a retry finishes a partial merge.
- Warranty extension: adds months to the end date with a reason, append-only `warranty_extensions`; void or manufacturer warranties cannot be extended.
- Migrations:
  - M37 Identity: `persons.customer_note`, `user_accounts.merged_into_account_id`, permissions.
  - M38 Retail: `warranty_extensions`.
- Code:
  - Identity `Customers/` (`CustomerAccounts`, `CustomerAdminService`, `CustomerMergeService`, `CustomerMergeRules`).
  - Retail `Domain/CustomerRules.cs`, `Features/Customers/CustomerSalesService.cs`, `WarrantyRules.Extend`.
  - Storefront `AccountRequestService`.
  - PcBuilder `SavedBuildStore.MoveOwnerAsync`.
  - Host `CustomerEndpoints.cs`, `Customers/` (`CustomerProfileComposer`, `CustomerMergeOrchestrator`).
- Tests:
  - Unit `CustomerRulesTests` (+ Extend cases in `WarrantyRulesTests`).
  - Integration `CustomerAdminTests`.
