# Checkpoint: 2.11 Audit

Date: 14 Nov 2026

## Done
- Capture: `AuditSaveChangesInterceptor` (Common.Infrastructure) on every business DbContext, registered by `AddAuditedDbContextFactory<T>`. Writes Added, Modified, Deleted, SoftDeleted and Restored with before/after per changed scalar field (CLR property names). Written with plain SQL in the same transaction: opens and owns one if the caller had none, never commits a caller's. Bookkeeping fields (RowVersion, UpdatedAtUtc, DeletedAtUtc, DeletedByUserId) are not listed.
- Opt-out `ExcludeFromAudit()`: sessions, email outbox, email-change requests, notifications, email codes, authorization state, person-code counters, media usage rows, invoice counters, order events, wishlist items, article revisions, saved builds. The Auditing context itself is not intercepted.
- Masked as `"***"`: seller national ID, order tracking token, invoice access token, request photo token hash, every byte[] field.
- Actor `IAuditActor`: Host `HttpAuditActor` (user, IP, user agent, correlation id); Anonymous for guests; System for jobs.
- Storage: `audit_entries` (Auditing, M47): actor kind/user/IP/user agent/correlation, module, entity, entity id, action (Created, Updated, Deleted, SoftDeleted, Restored, ValuesRestored), changes jsonb, restored_from_entry_id. No FKs. A trigger rejects UPDATE, DELETE and TRUNCATE; the app role lost those grants.
- API `/api/v1/admin/audit`: `GET /entries` (filters actorUserId, module, entity, entityId, action, from/to Cairo days, default last 30; paged, max 100; newest first), `GET /entries/{id}`, `GET /filters`. Permission `System.ViewAuditLogs`. Export dataset `audit` in the 2.10 export.
- Restore previous values: `POST /entries/{id}/restore`, owner-only `Audit.Restore` (M48 Identity) + step-up. Only `Updated` entries of allowlisted kinds with explicit fields: stock item listing fields, build card fields, expense types, partner name/phone/default %, categories, brands, product descriptive fields, store settings sections except logos, articles, FAQ. 409 if the record changed since (lists the fields), if the kind is not allowlisted, or if the entry is not an `Updated` entry. Applies the old values, bumps the row version, logs `ValuesRestored` linked to the entry.
- Never restorable: money ledgers, stock state, orders, payments, warranties, partner ledgers, accounts and roles.
- Tests: AuditRulesTests (19), AuditChangeSetTests (12), AuditInterceptorTests (4), AuditLogTests (13). Full suite 958/958.
