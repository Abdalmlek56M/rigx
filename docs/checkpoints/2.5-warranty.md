# Checkpoint: 2.5 Warranty registry

Date: 13 Nov 2026

## Done
- Warranty snapshot per sold unit at stock claim (Confirmed): build part (part override → build warranty → item's own); stock line: item's own warranty. Stored on the order component.
- On Delivered: one record per sold unit with a warranty in `warranties`: RX code, name, condition, serial (snapshot), BLD code if sold in a build, label, months, start = delivery time, end = start + months (no end for "ضمان الوكيل"), customer phone and account. Status computed: Active / Expired / Void.
- Auto-void: Delivered order cancelled ("Order cancelled"); return accepted or inspected ("Returned"). A rejected return keeps the warranty.
- Manual void `POST /api/v1/admin/retail/warranties/{id}/void` (`Sales.ProcessReturn`, reason + RowVersion).
- Public lookup `GET /api/v1/warranty/lookup?q=` (anonymous, rate-limited 20 / 10 min per IP, policy `warranty-lookup`). Prefix parse: `RX-` item code, `RIGX-` order number (stands in for invoice number until `INV-` lands in 2.6), digits = phone, otherwise serial. Grouped per order; phone masked to last 3 digits; no name, full phone, serial or prices.
- Customer account list `GET /api/v1/warranties/mine`.
- Admin list `GET /api/v1/admin/retail/warranties?q=&status=&page=` (`Sales.ViewOrders`; name/phone with `Sales.ViewCustomerContact`; serial with `Inventory.ViewSerials`; 50 per page).
- Phone rule: Egyptian mobile in international form (+20… / 0020…) is stored and matched in local form (01…) everywhere (orders, blacklist, POS search, warranty lookup).
- Migration M26 (Retail: `warranties`, warranty snapshot on order components).
- Code: rules in `Retail/Domain/WarrantyRules.cs`; entity in `Retail/Domain/WarrantyEntities.cs`; features in `Retail/Features/Warranty/`: `WarrantyRegistry` (issue/void inside order and return transactions), `WarrantyService` (lookup, mine, admin, void). Host: `Retail/RetailEndpoints.Warranty.cs`.
- Tests: unit `WarrantyRulesTests`, integration `WarrantyPostgreSqlTests` (12), authorization matrix updated.
- Tests: full suite 468/468 (WarrantyRulesTests unit, WarrantyPostgreSqlTests 12 integration).
